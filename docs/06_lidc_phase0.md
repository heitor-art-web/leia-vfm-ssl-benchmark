# LIDC-IDRI Phase 0 — dataset contract

## Clinical task

The first pulmonary benchmark is deliberately narrow:

> **Segment volumetrically annotated pulmonary nodules >= 3 mm on chest CT with limited labelled data.**

This is a segmentation benchmark, not a cancer diagnosis claim. LIDC-IDRI contains subjective malignancy ratings, but malignancy prediction is outside Phase 0.

## Why LIDC-IDRI

LIDC-IDRI provides chest CT together with independent radiologist annotations. Nodules >= 3 mm have slice-by-slice contours. The original collection deliberately preserved reader disagreement rather than forcing a single consensus truth.

The benchmark uses that disagreement as information rather than silently collapsing it into background.

## Scope of the annotation parser

The first implementation uses `pylidc.Annotation`, which represents **volumetrically contoured nodules >= 3 mm**.

Important limitation: LIDC-IDRI also contains point marks for nodules < 3 mm and for non-nodules >= 3 mm. Those non-volumetric marks are not parsed by pylidc and are therefore outside the v1 segmentation target. Do not interpret a background pixel as a statement that every radiologist explicitly confirmed normal tissue there; it means only that the pixel is outside the current >=3 mm volumetric nodule target.

## Reader-vote target

For one clustered nodule, individual reader masks are first aligned into the same local bounding box. The benchmark then creates one semantic target:

- `1`: trusted nodule pixel — at least 3 of 4 possible readers include the voxel;
- `255`: ambiguous/unknown — 1 or 2 readers include the voxel;
- `0`: task background — no reader contour includes the voxel.

`255` is intentional. Ultralytics semantic segmentation treats pixel value `255` as ignore, so disputed pixels can be excluded from supervised loss instead of being forced into either foreground or background.

The 3-reader threshold is a **benchmark policy**, not a medical definition of truth. It must be fixed before model comparison and ablated later (for example 2/4 versus 3/4 consensus).

## CT intensity handling

Do not assume `DICOM.pixel_array` is already in Hounsfield units. Phase 0 explicitly applies each slice's:

- `RescaleSlope`
- `RescaleIntercept`

before windowing.

The initial deterministic window is:

```text
[-1000 HU, 400 HU]
```

This is a starting preprocessing contract, not a tuned hyperparameter.

## 2.5D input

YOLO26-sem is a 2D semantic model. To preserve limited through-plane context without changing the architecture, each exported RGB image uses adjacent CT slices as channels:

```text
R = z - 1
G = z
B = z + 1
```

At scan boundaries the nearest slice is repeated.

This should be treated as a benchmark design choice. A true 3D model is a later comparison, not silently mixed into Phase 0.

## Split rule

All train/validation/test and labelled/unlabelled partitions are **patient-level**.

Never put slices from the same patient in more than one partition.

The existing `scripts/make_splits.py` can create the 1%, 5%, 10% and 25% labelled subsets once the frozen training patient list has been defined.

## Export layout

The exporter writes Ultralytics semantic-mask format:

```text
dataset/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
├── masks/
│   ├── train/
│   ├── val/
│   └── test/
├── manifest_train.csv
├── manifest_val.csv
└── manifest_test.csv
```

Each mask is a lossless single-channel PNG with values `0`, `1`, or `255`.

All CT slices are exported by default. A debug-only `--drop-empty-slices` option exists, but benchmark training must not silently remove negative slices because that would alter class prevalence and make results difficult to interpret.

## Export command

After installing and configuring pylidc to point to the local LIDC-IDRI DICOM collection:

```bash
python scripts/export_lidc_semantic.py \
  --patient-list splits/train_patients.txt \
  --split train \
  --output data/lidc_yolo
```

Repeat with the frozen validation and test patient files.

## Phase 0 quality gates

Before any model is trained:

1. Patient IDs in train/val/test are disjoint.
2. Every image has exactly one same-stem mask.
3. Masks contain only `{0, 1, 255}`.
4. DICOM rescale metadata is applied before windowing.
5. A visual sample of consensus, ambiguous and background regions is reviewed against original CT and reader contours.
6. The manifest is frozen and versioned before benchmark runs begin.
7. No prediction generated by YOLO, MedSAM or another model is ever copied into human ground truth.

Phase 1 model work begins only after these gates pass.
